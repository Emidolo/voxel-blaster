# Voxel Blaster

3D color-matching puzzle in the browser. Upload any image and it becomes a voxel level: the background is removed, colors are quantized, and the shape is sculpted into a rounded 3D model. Pick shooters into 5 slots; each one fires only at exposed blocks of its color. Fill all 5 slots with nothing to shoot and you lose.

Includes a 12-level emoji campaign, sound effects and mobile vibration.

## Run

```bash
npm install
npm run dev
```

Built with React, Vite and three.js.
